# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| < 0.1.0 | No |

## Reporting a Vulnerability

Do not open public issues for security reports or publish exploit details before remediation.

Use GitHub private vulnerability reporting for this repository:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Include the affected version or commit, reproduction steps or proof of concept, impact assessment, and a suggested remediation when available.

If the private reporting channel is temporarily unavailable, do not disclose sensitive details publicly. Wait until a private channel is restored.

## Disclosure Policy

- Coordinated disclosure is followed.
- Reports are acknowledged and triaged privately.
- Fixes are prepared before public disclosure.
- Public notes are published after remediation when appropriate.

## Reporter Credit

Reporter credit is included in release notes unless anonymous attribution is requested.

## Scope Notes

PhantomOS can automate keyboard, clipboard, application control, and command execution. Security findings in these areas are treated as high priority.

For runtime controls and trust-level behavior, see [Docs/safety.md](Docs/safety.md).
